# InstaClone

InstaClone is a Flutter project created for learning and practicing Flutter app development.

## Main Folders

### `lib/`

The `lib/` folder contains the main Dart source code of the Flutter application.
Screens, widgets, models, services, and other application logic are normally placed here.

### `android/`

The `android/` folder contains the Android-specific project files and configuration.
It is used when building and configuring the Flutter application for Android devices.

### `ios/`

The `ios/` folder contains the iOS-specific project files and configuration.
It is used when building and configuring the Flutter application for iPhone and iPad.

### `test/`

The `test/` folder contains automated tests for the Flutter application.
It is used to test widgets, functions, and application logic to help ensure the code works correctly.
